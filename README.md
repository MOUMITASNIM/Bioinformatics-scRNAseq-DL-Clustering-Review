# Bioinformatics-scRNAseq-DL-Clustering-Review
A comparative literature review of nine deep learning-based clustering methods for single-cell RNA-seq data, organized into four methodological families and evaluated against a common set of open challenges. (CSE443 : Bioinformatics project (BRAC University)).


The analysis finds that graph-based methods report the largest and most 
consistent gains over classical baselines, that transformer foundation 
models such as scGPT prioritize cross-task generalization over 
single-benchmark accuracy, and that the field currently lacks a standardized 
benchmarking framework (analogous to CHM13/QUAST in genome assembly) — 
making it difficult to determine which architectural family is genuinely 
superior versus simply better tuned to its authors' chosen datasets.
